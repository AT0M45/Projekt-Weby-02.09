## Dokumentace - FitStart

Jednoduchý školní web o pohybových lekcích. Obsahuje responzivní navigaci, carousel se čtyřmi fotografiemi,
karty lekcí, ukazatel postupu, tabulku rozvrhu, formulář pro přihlášku na více lekcí a kontaktní formulář.

### Odkazy
GitHub: https://github.com/AT0M45/Projekt-Weby-02.09

Hlavním zdrojem pro HTML, CSS a Bootstrap byla dokumentace W3Schools: https://www.w3schools.com/

### Externí knihovny

Bootstrap 5.3.8, Font Awesome, Tom Select 2.6.2

### Spuštění projektu
Knihovny byly nainstalovány pomocí NPM. Lokální soubory knihoven jsou uložené ve složce assets, proto
web funguje i po nahrání na hosting. Web se otevře souborem index.html.
